SwiftUI-认识基本界面

发表于 2025-06-06 更新于 2025-06-07 分类于 SwiftUI学习

1.主区域

1.1 Navigator Area/导航区域

导航区域用于查找资源、定位书签、排错…

1.2 Debug Area/调试区域

代码区域与编辑区域共称调试区域

代码区域用于编辑项目代码

编辑区域跟随代码区域变动

1.3 Inspector Area/检查区域

检查区域用于显示当前资源属性、控件属性…

当代码区域定位到具体语法时，在检查区域可以视图方式调整值，随后编辑区域、代码区域被动同步

2.详细分区

2.1 Navigator/导航

2.1.1 Project Navigator/项目导航

项目导航用于资源查找

2.1.2 Source Control Navigator/资源控制导航

资源控制导航用于观察Git仓库变化及控制

2.1.3 Bookmark Navigator/书签导航

书签导航用于快速定位代码区域中的行书签

2.1.4 Find Navigator/查找导航

查找导航用于快速查找代码

2.1.5 Issue Navigator/错误导航

错误导航用于排错

2.1.6 Test Navigator/测试导航

测试导航用于测试代码API调用、生存周期…

2.1.7 Debug Navigator/调试导航

调试导航用于记录调试会话

2.1.8 Breakpoints Navigator/断点导航

断点导航用于对代码进行局部调试

2.1.9 Report Navigator/报告导航

报告导航用于记录构建会话，若构建失败后方会出现错误标识

2.2 Inspector/检查器

2.2.1 File Inspector/文件检查器

文件检查器用于显示当前编辑文件的名称、种类、路径…

2.2.2 History Inspector/历史检查器

历史检查器用于复盘之前的检查

2.2.3 Quick Help Inspector/快速帮助检查器

快速帮助检查器用于提示当前控件的语法和用途

2.2.4 Accessibility Inspector/易用性检查器

易用性检查器用于测试一些辅助功能如旁白

2.2.5 Attributes Inspector/属性检查器

属性检查器用于修改控件的属性，如文本控件的大小字体…

2.3 Toolbar/工具栏

红框部分共称工具栏

黄框部分控制导航区域和检查区域的显隐

绿框部分为构建按钮

蓝框部分为控件库，可拖拽至编辑区域

SwiftUI-首个项目创建

发表于 2025-06-03 更新于 2025-06-06 分类于 SwiftUI学习

1.获取Xcode

1.1 从“App Store”

可以从”App Store”快速获取稳定版及后续更新

1.2 从“Apple Developer官网”

可以从Xcode - Apple Developer快速获取Beta版及后续更新

2.正式创建

2.1 启动软件

2.2 软件类型

点击“Create New Project…”来到软件类型选择页面

根据自行需要所需选择

Note
当提示“xxx Not Installed”时，应点击后方“Get”以获取构建版本支持

2.3 新项目选项

选择好软件类型点击“Next”来到新项目选项页面

Product Name
产品名称。将应用于软件开启后菜单栏显示、鼠标停滞图标显示及软件窗口顶部

Team
团队。用于团队合作时项目共享，后续软件上架“App Store”须添加

Organization Identifier
组织标识。团队或公司名称

Bundle Identifier
捆绑标识。软件包名，前段为组织标识

Interface
接口。本次选择”SwiftUI”

Language
语言。接口选择”SwiftUI”后，默认使用”Swift”

Testing System
测试系统。用于操作反馈，代码单元测试及集成测试。本次选择“Swift Testing with XCTest UI Tests”

Storage
存储。用于数据持久化，将对象转为为数据存储，后续可还原

Host in CloudKit
云端主机。使用iCloud作为云端数据库，可用于跨平台同步

Note
标准的“Organization Identifier”写法
